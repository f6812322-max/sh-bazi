# sh-bazi

قابل اجرا روی گوشی: بله 📱
بدون نیاز به نصب برنامه: بله؛ با مرورگر باز می‌شود.

روش استفاده

۱. فایل را دریافت کنید.
۲. روی گوشی با مرورگر بازش کنید.
۳. برای ارسال به دانش‌آموزان، می‌توانید فایل را در کانال/گروه ارسال کنید؛ اگر کانال اجازه ارسال فایل HTML بدهد، دانش‌آموز فایل را دریافت و با مرورگر باز می‌کند.
